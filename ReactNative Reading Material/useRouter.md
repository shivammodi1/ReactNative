# useRouter in React Native
- useRouter is a hook provided by React Navigation library in React Native.
- Iske helps se we can navigate between different screens in our app.
- It gives some methods like navigate, goBack, push, replace, etc. to perform navigation actions.

## Methods of useRouter:
1. navigate: yeh simple 1 page se dusre page par navigate karne ke liye use hota hai.

2. goBack: yeh current page se previous page par wapas jane ke liye use hota hai.

3. push: yeh navigate ki tarah hi hota hai, lekin yeh same page par multiple times navigate karne ke liye use hota hai.

4. replace: yeh current page ko new page se replace karne ke liye use hota hai, aur back stack mein current page ko remove kar deta hai.

5. reset: yeh navigation state ko reset karne ke liye use hota hai, aur new state set karta hai.

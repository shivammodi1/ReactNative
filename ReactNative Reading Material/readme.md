# What is Expo 
- It is a react native framework .
- Using expo we can build cross platform apps for android and ios using react native.
- It provides a set of tools and services that make it easier to develop, build, and deploy React Native apps.
# Why Expo
- It provides a lot of built in features and libraries that make it easier to develop apps.
- It has a large community and a lot of resources available for learning and troubleshooting.
- It allows for easy testing and debugging on both Android and iOS devices.

# How to install Expo

- Alternatively, you can use npx to create a new Expo app without installing the CLI globally:
```bash
npx create-expo-app myApp
```

- Start the development server:
```bash
cd my-app
npm expo start
```
